# Admin Dashboard

Protected by NextAuth. Only the owner (Abdul Wahab) can log in.

## Sidebar Navigation
- Dashboard (stats overview)
- Projects (add / edit / delete)
- Blog Posts (add / edit / delete with TipTap editor)
- Testimonials (add / edit / toggle featured)
- Leads (view submissions, update status)
- Settings (update bio, social links, stats numbers)

## Dashboard Stats Cards
- Total Projects
- Total Blog Posts
- Total Leads (new vs contacted)
- Total Testimonials

## Admin UI Style
- Dark sidebar: `#1A0E2E`
- Content area: slightly lighter `#0f0720`
- Cards and tables use shadcn/ui components
- Fully responsive
